Modern Forms Breeze Fan

Owner's and dealer's manual for the Modern Forms Breeze Fan driver: the Breeze of a Modern Forms fan, shown on the Navigators as a second fan with three speeds, for a fan that runs on the Modern Forms Fan driver. This page is the Documentation tab of the Breeze fan in Composer.

1. What the Breeze fan is

Breeze is the mode in which a Modern Forms fan speeds up and slows down by itself, like a breeze, at one of three strengths. Control4's fan tile has no place for a mode like that, so the Modern Forms Fan driver puts Breeze on the Navigators (touch screens, remotes, the Control4 app) as a second fan device, named after the fan, for example Aviator 5 Breeze. It is listed with the room's fans and has three speeds: Breeze 1, Breeze 2 and Breeze 3. Choosing one starts Breeze at that strength; turning the Breeze fan off ends Breeze.

  • It only passes messages. The Breeze fan never talks to the fan. It is bound to the fan's Modern Forms Fan device (its input Modern Forms Fan on the fan device's output Breeze Switch, binding 400), which sends the fan every command, decides what a tap means from what the fan is doing, and tells the Breeze fan what the fan does.
  • It shows what the fan confirms. The Breeze fan shows a Breeze speed only once the fan reports Breeze at that strength, and shows off only once the fan reports Breeze ended. A change made with the remote, the wall control or the Modern Forms app shows up as soon as the fan driver sees it (within its poll, 15 seconds by default).
  • It has no light and no direction: Breeze is one thing the motor does, nothing more.

This is an independent driver. It is not made, endorsed or supported by Modern Forms, WAC Lighting or Snap One (Control4); the trademark notices are at the end of this page.

2. Fan mode and Breeze mode

The fan has one motor, and it is always in one of three states:

The fanThe main fan (Aviator 5)The Breeze fan (Aviator 5 Breeze)
StoppedOffOff
Running in fan mode, at one of its own speedsOn, at that speedOff
Running in Breeze mode, at Breeze strength 1, 2 or 3Off (its speeds mean nothing in Breeze)On, at Breeze 1, 2 or 3

Never both. Choosing a Breeze speed ends fan mode; choosing a fan speed on the main fan ends Breeze. So while Breeze blows, the main fan shows off even though the blades turn. That is intended: each device shows its own mode.

The keypad while Breeze blows. A keypad's buttons on the main fan's links show the same: the speed, Toggle and Cycle buttons are dark, and so is the Off button, because Off would stop the motor. A button on the main fan's Fan Breeze link is lit. With the main fan's Breeze LED Animation set to Gusts, the speed buttons play gusts instead of staying dark, and the gusts pause while a keypad connected to the main fan's Ambient Light Level (Follower) input is dark (the main fan's Documentation tab, in its chapter on keypad buttons).

3. Adding the Breeze fan

The Breeze fan needs the Modern Forms Fan driver of the same release, with the fan set up, on a fan that has Breeze (its Fan Model row ends in , Breeze). Install this driver file, modernforms_breeze_fan.c4z, together with the fan driver; it is part of every release since 1.3.

  1. Select the fan item (the Modern Forms Fan) and click its action Add Breeze Fan. The fan driver adds a Modern Forms Breeze Fan device to the fan item's room, names it after the fan item plus Breeze, binds it to the fan (binding 400, Breeze Switch), and says so in the fan item's Last Action, for example Breeze fan added: Aviator 5 Breeze.
  2. In the room's Navigator order in Composer, move Aviator 5 Breeze right after Aviator 5, so the two sit together on the touch screens and in the app. Control4 has no way for a driver to place it there itself.
  3. Choose File ▸ Refresh Navigators, so the touch screens and the app show the new device.

By hand: add the Modern Forms Breeze Fan driver to a room yourself, then in Connections bind its Modern Forms Fan input to the fan device's Breeze Switch output, and refresh the Navigators. Two Breeze fans bound to one fan both work and always agree.

The fan driver adds a Breeze fan only when you click, never by itself. It refuses with a line in the fan item's Last Action when the fan is not set up (No Breeze fan added: set up the fan first), when the fan has no Breeze (No Breeze fan added: this fan reports no Breeze), when a Breeze fan is already bound (A Breeze fan is already connected: Aviator 5 Breeze), and when Composer could not add it (No Breeze fan added: install modernforms_breeze_fan.c4z first).

The Breeze fan's name and room are yours: rename it or move it to another room at any time; neither driver ever renames or moves it. Deleting it is safe too: the fan forgets it, and Add Breeze Fan adds a new one whenever you want. Its own programming goes with it, which is one more reason to program Breeze on the fan item (chapter 5).

Replacing the Breeze switch of release 1.2

Release 1.2 showed Breeze as an on/off light switch (the Modern Forms Breeze driver, modernforms_breeze.c4z). Control4 cannot turn an installed light into a fan, so the Breeze fan is a new device that replaces the switch:

  1. Note any programming that names the old switch: it goes with the switch. Rebuild what you want to keep on the fan item (chapter 5), not on the new device.
  2. Delete the old switch. While it is still bound, Add Breeze Fan refuses with Delete the old Breeze switch first: Aviator 5 Breeze.
  3. Click Add Breeze Fan, place the new device after the fan and refresh the Navigators, as above.

4. Using it

You do on the Breeze fanThe fan does
Choose Breeze 1, 2 or 3Breeze at that strength. From fan mode the fan switches to Breeze (the main fan goes off); a stopped fan starts straight in Breeze.
Turn it onBreeze at the strength the fan used last, from fan mode or from a stop. Nothing changes while Breeze already blows.
Turn it off while Breeze blowsThe fan stops. Breeze ends with it, so the next start from anywhere is plain fan mode. To go back to fan mode without stopping, choose a speed on the main fan instead.
Turn it off while it already shows offA stopped fan forgets a Breeze it kept set (the remote can leave one). A fan running in fan mode is left alone: the Breeze fan never stops a fan in fan mode.
ToggleOn or off as above, decided by the fan driver from what the fan is doing, so two quick taps end where they should.
Speed up / speed downUp from off or from fan mode gives Breeze 1; down from there does nothing. In Breeze each step changes the strength by one, and stays at Breeze 3 or Breeze 1 at the ends (it never wraps round and never turns off).

The Breeze fan changes when the fan confirms, usually within two seconds of a tap. If it does not change, or springs back, the fan did not do it: the fan item's Last Action says why.

On the main fan, everything works in fan mode: a speed or a keypad speed button ends Breeze and runs the fan at that speed, On and Toggle end it and run the fan at its preset speed, and Off stops the fan and ends Breeze.

When the fan is away (offline, for example after a wall switch cut its power, or not set up), a fan tile cannot be greyed out, so the Breeze fan keeps showing what it showed last and its Status reads Waiting for Aviator 5. It comes back by itself when the fan does. A fan without Breeze shows off, and a Breeze fan that is not bound to a fan shows off and does nothing.

The Breeze fan's item in Composer shows the fan proxy's Preset Level setting. It means nothing here: the Breeze fan has no preset, and on always resumes the fan's own last strength.

5. Programming, keypads, groups and voice

  • Program Breeze on the fan item. It has the commands Breeze On, Breeze Off, Toggle Breeze and Set Breeze Strength, the events Breeze Started and Breeze Stopped, the condition Breeze is on and the Breeze variable (the fan item's Documentation tab). Those lines stay when the Breeze fan is deleted and added again; lines written on the Breeze fan go with it. Breeze Off follows the Breeze fan's off: it stops the fan while Breeze blows.
  • The Breeze fan also has the events, conditions and commands of any Control4 fan (turned on, turned off, speed changed, "Set speed Breeze 2" and so on), and its speed changed fires when the strength changes. They are fine for a quick line; keep lasting programming on the fan item.
  • Lines on the main fan's events also run when Breeze starts, because the main fan turns off then (for example "when the fan turns off, turn its light off"). Add the condition Breeze is on (set to false) to such a line, or use Breeze Started and Breeze Stopped.
  • Do not write lines that answer each other across the two devices ("when the Breeze fan turns off, set the fan to Level 2" and "when the fan turns off, choose Breeze 1"): each start turns the other off, and they run at the fan's pace, forever.
  • Keypads: the Breeze fan has no Button Links. A keypad button for Breeze is bound to the fan item's Fan Breeze Button Link (it lights while Breeze blows), or programmed with the Breeze fan's Set speed or the fan item's Set Breeze Strength. The buttons on the fan item's speed links can show Breeze as gusts (chapter 2).
  • "All fans on" starts Breeze too: it turns on both devices, which ask for opposite modes, and the fan ends up in whichever arrived last. Keep the Breeze fan out of "all fans on" groups and scenes that turn fans on. "All fans off" is fine: it stops the fan and ends Breeze.
  • A voice assistant sees a fan named Aviator 5 Breeze; "turn on the fans" is the same case as "all fans on" above.

8. Limits

  • Three Breeze strengths, on and off; no direction, no preset, no fades, no light.
  • One fan per Breeze fan. The Breeze fan follows the fan device it is bound to; binding it to another fan device moves it there.
  • Changes made outside Control4 appear at the fan driver's next poll (15 seconds by default).
  • Controllers: Control4 OS 3.3.0 or newer, the same as the fan driver.
