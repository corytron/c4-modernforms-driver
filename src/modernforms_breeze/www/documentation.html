Modern Forms Breeze

Owner's and dealer's manual for the Modern Forms Breeze driver: a switch on the Navigators for the Breeze of a Modern Forms fan that runs on the Modern Forms Fan driver. This page is the Documentation tab of the Breeze switch in Composer.

1. What this switch does

Breeze is the mode in which a Modern Forms fan speeds up and slows down by itself, like a breeze. Control4's fan tile has no place for a mode like that, so the Modern Forms Fan driver puts Breeze on the Navigators (touch screens, remotes, the Control4 app) through this small companion: a switch named after the fan, for example Aviator 5 Breeze, in the room's lights. It is lit while the fan blows a Breeze, and a tap starts or ends Breeze.

  • It only passes messages. The switch never talks to the fan. It is bound to the fan's Modern Forms Fan device, which sends the fan every command and tells the switch what the fan does.
  • It shows what the fan confirms. The switch lights only once the fan reports Breeze, and goes dark only once the fan reports it ended. A change made with the remote, the wall control or the Modern Forms app shows up as soon as the fan driver sees it (within its poll, 15 seconds by default).
  • "Blowing" means running with Breeze. A fan that is off with Breeze still set in it is not blowing anything, so the switch is off; the fan item's Status then reads Breeze set.

This is an independent driver. It is not made, endorsed or supported by Modern Forms, WAC Lighting or Snap One (Control4); the trademark notices are at the end of this page.

2. Adding the switch

The switch needs the Modern Forms Fan driver of the same release, with the fan set up and answering, on a fan that has Breeze (its Fan Model row ends in , Breeze). Install this driver file, modernforms_breeze.c4z, together with the fan driver; it is part of every release.

  1. Select the fan item (the Modern Forms Fan) and click its action Add Breeze Switch. The fan driver adds a Modern Forms Breeze device to the fan item's room, names it after the fan item plus Breeze, binds it to the fan, and says so in the fan item's Last Action, for example Breeze switch added: Aviator 5 Breeze.
  2. Choose File ▸ Refresh Navigators, so the touch screens and the app show the new switch.

By hand: add the Modern Forms Breeze driver to a room yourself, then in Connections bind its Modern Forms Fan input to the fan device's Breeze Switch output, and refresh the Navigators. Two switches bound to one fan both work and always agree.

The fan driver adds a switch only when you click, never by itself. It refuses with a line in the fan item's Last Action when the fan is not set up (No Breeze switch added: set up the fan first), when the fan has no Breeze (No Breeze switch added: this fan reports no Breeze), when a switch is already bound (A Breeze switch is already connected: Aviator 5 Breeze), and when Composer could not add it (No Breeze switch added: install modernforms_breeze.c4z first).

The switch's name and room are yours: rename it or move it to another room at any time; neither driver ever renames or moves it. Deleting it is safe too: the fan forgets it, and Add Breeze Switch adds a new one whenever you want.

3. Using it

You doThe fan does
Tap the switch while it is offBreeze starts. A fan that is off is first started at its preset speed (the fan item's Preset Level, Level 3 until you change it), then Breeze starts.
Tap the switch while it is onBreeze ends. The fan keeps turning at its speed; turn it off on the fan tile.
Turn the fan off on its tile, remote or wall controlThe switch goes off: nothing blows. The fan keeps Breeze set (the fan item's Status reads Breeze set) and is expected to blow a Breeze again the next time it starts; the switch lights when it does.

The switch changes when the fan confirms, usually within two seconds of a tap. If it does not change, the fan did not do it: the fan item's Last Action says why.

Greyed out means the switch cannot act now: it is not bound to a fan, the fan has no Breeze, or the fan is away (offline, not set up, or another fan answers at its address). Its Status says which (chapter 5). It comes back by itself when the fan does.

The Breeze strength (1 to 3) is not on the switch: set it with the fan item's programming command Set Breeze Strength or in the Modern Forms app.

4. Lighting groups, scenes, voice and programming

To Control4 the switch is an ordinary on/off light, so anything that switches lights may switch it too:

  • Keep it out of "all lights on" groups and lighting scenes that turn lights on: turning it on starts the fan. In "all lights off" it does no harm: off ends Breeze and the fan keeps turning.
  • It cannot join an Advanced Lighting Scene.
  • A voice assistant or a "lights on" count may list it among the room's lights; leave it out there if you prefer.
  • Programming: the switch has the light events and commands of any switch. For Breeze itself the fan item is the better place: the commands Breeze On, Breeze Off, Toggle Breeze and Set Breeze Strength, the events Breeze Started and Breeze Stopped, the condition Breeze is on and the Breeze variable (the fan item's Documentation tab). Do not write two lines that answer each other ("when it turns on, turn it off" and back): they run at the fan's pace, forever.
  • A keypad button for Breeze is bound to the fan item's Fan Breeze Button Link, not to this switch, which has no Button Links.

7. Limits

  • On and off only: no strength on the switch, no fades.
  • One fan per switch. The switch follows the fan device it is bound to; binding it to another fan device moves it there.
  • Changes made outside Control4 appear at the fan driver's next poll (15 seconds by default).
  • Controllers: Control4 OS 3.3.0 or newer, the same as the fan driver.
